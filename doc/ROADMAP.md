# Roadmap

The maintained application is C++ with Qt Quick. The
[operational specification](spec/podlord-operational-spec.md) owns behavior.
The [test map](spec/k3d-test-map.md) identifies the public verification
boundaries. [Release channels](../docs/release-channels.md) records publisher
requirements.

Current work is tracked in issues and draft pull requests. A release requires
qualification of the exact source revision, packaged runtime checks on claimed
platforms, an owned Kubernetes journey, accessibility review, and the required
signing and publisher steps. Historical green runs do not qualify later edits.
