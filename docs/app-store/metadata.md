## English (U.S.)

**Name:** PodLord

**Subtitle:** Kubernetes desktop console

**Promotional text:** Inspect Kubernetes resources without losing the context of your work.

**Keywords:** kubernetes,kubeconfig,cluster,containers,devops,developer

**Description:**

PodLord is a native desktop console for everyday Kubernetes work. Import a kubeconfig, inspect resources across namespaces, read details and logs, and take the next useful action without rebuilding context in a terminal.

PodLord keeps cluster data close to the source you choose. It makes sensitive values deliberate, hides secret values by default and gives you a focused view for exploration, inspection and controlled actions.
