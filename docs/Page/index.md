# Podlord

A fast, cache-first desktop Kubernetes operations console.

[Documentation](documentation.html) | [Download](https://github.com/YunaBraska/podlord/releases/latest) | [Install](install.html)

## What it does

- Imports kubeconfigs into explicit Podlord-owned snapshots.
- Explores resources across namespaces without a mandatory YAML-first workflow.
- Provides native port forwarding, metrics, logs and a resource inspector.
- Redacts secret values by default.
