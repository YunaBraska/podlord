# Install

[Documentation](documentation.html) | [Install](install.html) | [Podlord](index.html)

## Download

1. Open the [latest release](https://github.com/YunaBraska/podlord/releases/latest).
2. Download the archive for Apple silicon or Intel Macs.
3. Move `Podlord.app` to Applications.

## Homebrew

```sh
brew tap yunabraska/tap
brew install --cask podlord
```
